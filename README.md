# TutorialChain

A decentralized educational tutorial and learning content exchange platform for sharing knowledge on Stacks blockchain.

## Features

- Tutorial publishing with comprehensive learning content
- Educator lesson management and validation
- Subject classification system
- Learning level specification and tracking
- Tutorial access management and restriction controls

## Smart Contract Functions

### Public Functions
- `publish-tutorial` - Publish new educational tutorial with content
- `restrict-tutorial` - Restrict tutorial access (educator only)

### Read-Only Functions
- `get-tutorial` - Get educational tutorial details
- `get-educator` - Get tutorial educator information
- `get-total-tutorials` - Get total published tutorials
- `get-access-status` - Get tutorial access status

## Subjects
- Mathematics, Science, Programming, Language, Arts, Business

## Learning Levels
- Beginner, Basic, Intermediate, Advanced, Expert

## Usage

Deploy the contract to create an educational platform where educators can publish their tutorials and manage access throughout the learning community.
